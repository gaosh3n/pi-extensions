# pi-extensions

Extensions for [Pi](https://github.com/earendil-works/pi), a minimal agent harness.

## Packages

| Package                                                       | Description                                                                                   |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| [`pi-package-manager`](packages/pi-package-manager/README.md) | A Pi extension for keeping package updates, installs, and uninstalls organized and visible.   |
| [`pi-peer-addon`](packages/pi-peer-addon/README.md)           | An add-on built on top of Pi extension [`pi-peer`](https://github.com/shift-labs-ai/pi-peer). |
